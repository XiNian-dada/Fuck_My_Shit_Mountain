JWT Secret 在生产环境变量缺失时静默降级为弱硬编码默认值

src/config/auth.ts:15 · getJwtSecret()
证据链 (Direct Code Evidence)
export function getJwtSecret(): string { // 缺陷代码：生产环境未设环境变量时静默吞错并降级为明文字符串 return process.env.JWT_SECRET || 'dev-secret-do-not-use-in-production'; }
现实危害场景 (Realistic Failure Scenario)
当容器部署时 JWT_SECRET 注入遗漏或配置文件被截断，服务端不会抛出任何异常，而是使用公开的 dev-secret... 进行签名验证。任何攻击者均可脱机伪造任意管理员 Claim 的合法 JWT Token，完全绕过全站鉴权。
最小安全修复 (Minimal Targeted Fix)
export function getJwtSecret(): string { const secret = process.env.JWT_SECRET; if (!secret) { throw new Error('FATAL: JWT_SECRET environment variable is mandatory for security.'); } return secret; }
High 高危 Confirmed 已确认 并发与原子性 预估工时: 2h

扣减库存操作存在 TOCTOU 竞态条件，高并发下导致超卖

src/services/inventory.ts:88 · deductStock()
现实危害场景 (Realistic Failure Scenario)
代码先执行 SELECT current_stock FROM items，然后在内存中校验 stock > 0，最后发出 UPDATE items SET stock = stock - 1。两个并发请求在读到相同库存快照后均通过校验，造成真实业务超卖。
