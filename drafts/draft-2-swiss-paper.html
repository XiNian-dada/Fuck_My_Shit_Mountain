JWT Secret 在环境变量未设定时回退为硬编码常量，引发全站身份伪造

📁 src/config/auth.ts:15 · 方法: getJwtSecret()

问题剖析： 函数内部使用或操作符 (||) 设定了 fallback 默认密钥。在容器部署或云原生环境因环境变量注入延迟时，服务将使用静态字符串签发与验签。攻击者可脱机伪造任意声明（包括超级管理员权限）的合法 Token，完全穿透鉴权系统。

推荐最小修复实施方案 TypeScript 
export function getJwtSecret(): string {
  const secret = process.env.JWT_SECRET;
  if (!secret) {
    throw new Error('FATAL: JWT_SECRET 必须在环境变量中明确配置，禁止静默回退。');
  }
  return secret;
}

库存扣减未处于行级锁保护下，引发 TOCTOU 竞态超卖

📁 src/services/inventory.ts:88 · 方法: deductStock()

问题剖析： 查询库存与写入扣减分为两条独立的无锁 SQL。高并发压测场景下两个请求同时读取到相同的库存数，导致商品库存被扣成负数。

推荐原子更新修复 SQL 
-- 使用原子条件更新替代应用层先查后改
UPDATE inventory 
SET stock = stock - :quantity 
WHERE product_id = :id AND stock >= :quantity;
