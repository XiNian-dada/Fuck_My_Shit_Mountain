JWT Secret 在容器环境变量缺省时静默回退至静态明文
src/config/auth.ts:15 · getJwtSecret()
收起详情 ▴

攻击路径： 当生产 K8s ConfigMap 或 Docker 容器因疏忽未注入 JWT_SECRET 时，代码由于回退逻辑不会报错，而是使用默认 'dev-secret...' 运行。攻击者利用该公开密钥可脱机签发伪造的有效 Admin Token。 

// 原始缺陷代码 (File: src/config/auth.ts:15)
export function getJwtSecret(): string {
  return process.env.JWT_SECRET || 'dev-secret-do-not-use-in-production';
}

// 推荐安全防护改造:
export function getJwtSecret(): string {
  const secret = process.env.JWT_SECRET;
  if (!secret) {
    throw new Error('FATAL: JWT_SECRET environment variable is mandatory!');
  }
  return secret;
}
